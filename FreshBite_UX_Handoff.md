# FreshBite — Food Ordering App UI/UX

## Deliverable
Interactive responsive HTML prototype covering the internship brief.

### Screens
1. Onboarding
2. Home / restaurant discovery
3. Restaurant list with search/filter
4. Restaurant detail + categorized menu
5. Menu item detail + customization
6. Shopping cart + quantity controls + totals
7. Checkout (address, payment, order summary)
8. Real-time order tracking
9. User profile / order history / saved addresses
10. Login / signup

### Design system
- Primary: #E84D8C
- Secondary: #FF6B6B
- Accent: #FCD34D
- Background: light pink
- Text: #1A1625
- Typography: Poppins headings, Inter body
- Rounded cards, subtle shadows, gradient CTAs, image/emoji-rich food visuals
- Responsive mobile-first layout with bottom navigation

### Main prototype flow
Onboarding → Home → Restaurant → Menu Item → Cart → Checkout → Order Tracking.
